# Todo Reminder – React Native\n\nSimple offline-first To-Do + Reminder app built with React Native and Expo.\n\n## Features\n- Create tasks\n- Set date/time reminders\n- Android local notifications\n- Offline storage with AsyncStorage\n- Mark complete / delete\n- All, Active, Done filters\n\n## Local run\n```bash\nnpm install\nnpx expo start\n```\n\n## Build APK\nThis branch includes a GitHub Actions workflow that prebuilds Android and runs `./gradlew assembleRelease`. The APK is uploaded as a workflow artifact.\n
