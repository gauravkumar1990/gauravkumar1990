# Roadmap
- v0.2 alpha: npm CLI/UI package, working web target, Zig core protocol, Android shell, tests.
- v0.3 alpha: ZigUI Studio visual editor, phone/tablet/web simulator, drag/drop tree, click-to-select inspector, source write-back.
- v0.3 native: QuickJS-NG embedding, JNI batched bridge, Android native widgets, ADB device hot reload, debug APK.
- v0.4: SQLite, HTTP, camera, notifications, files, signed APK/AAB.
- v0.5: iOS UIKit adapter and macOS build/sign pipeline.
- v0.6: keyed reconciliation, list virtualization, animations, accessibility, profiling.
